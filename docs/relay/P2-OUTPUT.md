- `tests/setup.test.js` — `loadApiCtx` now loads the full `gas/*.gs` bundle with the full mock set (Api.gs's router now depends on Auth/Users/Posts/.../Admin, so the old 2-file/2-mock load no longer boots); version assertion updated to `0.2.0`. Test intent (doGet/doPost/ping/BAD_JSON) is unchanged.
- `package.json` — added `build:seed` script; `gas:push` now runs `build:seed` first.
