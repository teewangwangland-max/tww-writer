### T2 `Db.gs`
- `db_()` → spreadsheet from `SHEET_ID` (cache in a global var per execution).
- `readAll_(tab)` → array of objects keyed by SCHEMA headers (row 1 skipped; empty rows skipped). Each object gets hidden
  `_row` (1-based sheet row number) — strip `_row` before returning anything to the client.
- `append_(tab, obj)` → builds a row in SCHEMA order (missing → `''`), `appendRow`. Returns obj.
- `updateRow_(tab, rowNumber, patch)` → writes only the patched columns of that row (one `setValue` per changed cell or one
  `setValues` for the full row read-modify-write). Never touches other rows.
- `findBy_(tab, key, value)` → first object or null.
- `newId_(prefix)` → `prefix + '_' + Utilities.getUuid().replace(/-/g,'').slice(0,12)`.
- `nowIso_()` → `new Date().toISOString()`.
- All writes wrapped by callers in `withLock_(fn)` = `LockService.getScriptLock()`, `waitLock(10000)`, finally `releaseLock()`.
- JSON columns (`*_json`) are stored as strings; helper `parseJson_(s, fallback)`.
- No function may delete rows, clear ranges, trash files or delete sheets.

### T3 `Auth.gs`
- `hashPassword_(password, saltHex)`: `h = saltHex + ':' + password`; repeat `HASH_ITERATIONS` times:
  `h = hex(Utilities.computeDigest(Utilities.DigestAlgorithm.SHA_256, h, Utilities.Charset.UTF_8))`. Return hex string.
  `hex(bytes)` must handle signed bytes (`(b < 0 ? b + 256 : b).toString(16).padStart(2,'0')`).
- `newSalt_()` → hex of SHA-256 of `Utilities.getUuid() + Date.now()` (first 32 hex chars).
- `sha256Hex_(s)` single digest helper (for token hashing).
- Constant-time-ish compare helper `safeEqual_(a,b)`.
- `auth.login {username, password}` (no token needed): username case-insensitive, trimmed. Lockout: CacheService script cache key
  `fail:<username>`; if count ≥ `LOGIN_MAX_FAILS` → `{ok:false,error:'LOCKED'}`. Wrong user or wrong password → increment count
  (TTL `LOGIN_LOCK_SECONDS`) and return the same `BAD_CREDENTIALS` for both. User with `active` not truthy (`TRUE`, true, 'TRUE') → `BAD_CREDENTIALS`.
  Success → clear fail count; token = two `getUuid()` joined without dashes (64 hex chars); append Sessions row
  `{token_hash: sha256Hex_(token), user_id, created_at, expires_at: now+SESSION_DAYS, last_seen_at}`; return
  `{ token, user: publicUser_(u) }`.
- `publicUser_(u)` → `{ user_id, username, display_name, role, playfulness_default (number), catchphrases, avoid_list }` — never hash/salt.
- `requireUser_(body)` → look up Sessions by `sha256Hex_(body.token)`; missing/expired → throw `ApiError('UNAUTHORIZED')`.
  Update `last_seen_at` at most once per hour (compare timestamps) to limit writes. Return the Users object.
- `requireAdmin_(body)` → requireUser_ + role === 'admin' else `FORBIDDEN`.
- `auth.me` → `{ user }`. `auth.logout` → set that session's `expires_at` to now (update, not delete). `auth.changePassword
  {oldPassword, newPassword}` → verify old; new length ≥ 8 else `WEAK_PASSWORD`; new salt + hash.
- `ApiError(code, message)` = function constructor or class producing `{code, message}`; router converts to `{ok:false,error:code,message}`.

### T4 `Api.gs` router
- Keep `doGet` (health) and `jsonOut_`. `doPost(e)`: if `e.postData.contents.length > MAX_BODY_BYTES` → `TOO_LARGE`. Parse JSON

  Any other exception → `{ok:false, error:'SERVER_ERROR', message: String(err.message||err)}` and `console.error`.

### T5 Users

### T6 Posts
- `posts.list { scope:'all'|'mine'|'friends', q? }` → rows WITHOUT `inputs_json/results_json/narrative_json/tone_json/body`;
  each row adds `author_name` (display_name) and `format_name` (latest version name of that format_id). `mine` = user_id == me;
  `friends` = user_id != me; `q` = case-insensitive substring on project_name or location. Sort `updated_at` desc, max 200.
- `posts.get { post_id }` → full row with JSON columns parsed to objects (`inputs`, `results`, `narrative`, `tone`), plus author_name. Any logged-in user may read.
- `posts.save { post: {post_id?, format_id, project_name, location, post_status, case_summary, inputs, results, narrative, tone, body},
  createDoc?: boolean, saveAsExample?: boolean }`:
  - New (no post_id) → append with new id `post`, user_id = me, timestamps. Existing → must exist and `user_id === me` else `FORBIDDEN`;
    update the row (only the listed columns + updated_at).
  - Validate: format_id non-empty, project_name non-empty (≤ 200), post_status ∈ POST_STATUSES (default 'draft'), body ≤ 60000 chars.
  - `createDoc:true` → `DocumentApp.create(title)` with title `"<project_name> · <author display_name> · <YYYY-MM-DD>"`, body text = post body,
    then `DriveApp.getFileById(doc.getId()).moveTo(DriveApp.getFolderById(DOCS_FOLDER_ID))`; store `doc.getUrl()` in `doc_url`.
    If the post already has a doc_url, create a NEW doc anyway (never overwrite an existing Doc) and replace doc_url.
  - `saveAsExample:true` → set `is_style_example` TRUE and append an Examples row
    `{owner: me, format_id, title: project_name, body, source:'post', source_ref: post_id, created_by: me, active: TRUE}`
    unless an active Example with the same `source_ref` exists (then update its body/title instead).
  - Returns `{ post: <as posts.get> }`.

### T7 Formats (versioned, append-only)
- Rows are versions. "Latest" of a format_id = row with max `version`.
- `formats.list` → for each format_id its latest row as `{format_id, name, version, status, updated_at}`; non-admin sees only
  formats whose latest status is `published`; admin sees all.
- `formats.get { format_id, version? }` → `{ format_id, name, version, status, spec }` (spec parsed). Non-admin cannot get a format whose latest is draft (`NOT_FOUND`).
- `formats.save { spec, status }` (admin) → spec must be an object with string `id` matching `^[a-z0-9][a-z0-9-]*$` and string `name`
  (full validation happens in the browser engine; server does only this sanity check + JSON size ≤ 100000). Append a NEW row with
  `version = latest+1` (or 1), `format_id = spec.id`, `name = spec.name`, status ∈ FORMAT_STATUSES. Never updates old rows.

### T8 Examples
- `examples.list { format_id?, owner? }` → active examples (owner may be a user_id or `HOUSE`), newest first, body included, max 100.
- `examples.add { owner?, format_id, title, body }` → owner defaults to me; owner `HOUSE` requires admin; another user's id → `FORBIDDEN`.
- `examples.importDoc { doc: <url or id>, format_id, owner? }` → extract id with `/\/d\/([a-zA-Z0-9_-]{20,})/` or accept a bare id;
  `DocumentApp.openById(id).getBody().getText()`; title = doc name; append Example `{source:'doc', source_ref: id}`; if an active example
  with that source_ref exists → return it with `duplicate:true` (no new row). Doc not accessible → `DOC_NOT_ACCESSIBLE`.
- `examples.importFolder { folder_id, format_id, owner_user_id }` (admin) → iterate `DriveApp.getFolderById(folder_id).getFilesByType(MimeType.GOOGLE_DOCS)`,
  import each like importDoc (skip duplicates), stop before 5 minutes of runtime (check elapsed ≥ 270 s) and report
  `{ imported, skipped, remaining: boolean }` so it can be re-run safely.

### T9 Style DNA (versioned, append-only)
- scope = `HOUSE` or a user_id. Read: any user may read HOUSE and own scope; reading another user's scope → FORBIDDEN (except admin).
  Write: HOUSE → admin only; own user_id → that user; others → FORBIDDEN.
- `styledna.get { scope }` → latest version `{ scope, version, dna, changelog, source_example_ids, created_by, created_at }` or `null`.
- `styledna.history { scope }` → all versions (without dna body is NOT required — include dna), newest first.
- `styledna.save { scope, dna, changelog, source_example_ids }` → append version = latest+1; `dna` stored as JSON string (object or string
  accepted, ≤ 50000 chars); `changelog` required non-empty (≤ 5000); `is_current` written as `''` (unused; current = max version).
- `styledna.rollback { scope, to_version }` → append a new version copying `dna_json` of `to_version`, changelog `"ย้อนกลับไปใช้ v<to_version>"`.
